# Security

## Reporting a problem

Please report security problems privately, not in a public issue.

Use GitHub's private reporting: open the [Security tab](https://github.com/harrypakhale98/Splt/security) of this repository and choose Report a vulnerability. Include what you found, how to reproduce it and which version you tested.

You can expect a first reply within a week. Splt is run by one person, so fixes may take longer, but reports are taken seriously and you will be kept informed. Please give a reasonable time to fix before sharing details.

## Scope

Splt has no server. The areas that matter are the app itself, how it stores data on the device, and how it uses iCloud to sync and share groups.

## Supported versions

The latest release on the App Store and the `main` branch.
